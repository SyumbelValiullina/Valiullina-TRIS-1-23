## 1. Название и организация

- Название системы: Маркетплейс услуг для малого бизнеса
- Организация / подразделение: Учебная платформа услуг для малого бизнеса «БизнесПомощь», Казань
- № из таблицы примеров: 80

## 2. Главная сущность и справочник

- Главный объект: заявка на услугу
- Справочник: категория услуги (бухгалтерия, юрист, дизайн, логистика)
- Поле-ссылка: categoryId

## 3. Роли и права

| Роль | Создаёт | Назначает | Меняет статус |
|---|---|---|---|
| Заказчик (малый бизнес) | да | нет | нет |
| Менеджер платформы | нет | да | нет |
| Исполнитель | нет | нет | да, только свою |

Исполнитель не назначает себя.

## 4. Сценарий в одно предложение

Заказчик создаёт заявку → менеджер назначает исполнителя → исполнитель меняет статус только своей заявки.

## 6. Что не входит в семестр

- оплата
- рейтинги исполнителей
- чат между заказчиком и исполнителем
- мобильное приложение
- SMS и e-mail-уведомления
- договоры

## 7. Запас под ВКР

- рейтинги исполнителей по закрытым заявкам
- онлайн-оплата через платёжный сервис
- выгрузка актов в 1С
- уведомления в Telegram
- отчёт о том, сколько часов заявка находится в каждом статусе

## 8. Чем не копия соседа

Заказчик: малый бизнес, три роли, категории услуг. (Уточните у одногруппников, нет ли такой же темы.)
