# Отчёт ЛР6

## Состояния списка

| Состояние | Как получено | Текст на экране |
|---|---|---|
| loading | вход на / | Загрузка… |
| empty | пустой массив в mock | Записей пока нет |
| data | mock с двумя записями | таблица |
| error | сбой запроса | сообщение об ошибке и кнопка «Повторить» |

## Три отказа

| Отказ | Как воспроизведён | Ветка | Текст человеку |
|---|---|---|---|
| 400 | тема «abc», клиентская проверка временно отключена | !response.ok | Проверьте поля |
| 500 | FORCE_500 = true в mock | !response.ok | Сервер не смог обработать запрос |
| Нет связи | USE_MOCK = false, сервер не запущен | catch | Нет связи с сервером |

## Защита от двойного клика

Во время запроса isSubmitting = true, кнопка disabled, в обработчике ранний return. Флаг снимается в finally.
